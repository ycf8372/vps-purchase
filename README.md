## 一、先搞清楚搬瓦工的几条美国线路

搬瓦工在美国有多个机房，但并不是所有机房都一样。线路差异直接决定了你访问速度和稳定性，比 CPU 和内存更值得先关注。

**普通 KVM 线路（DC2 / DC8 等）**

这是搬瓦工最便宜的一档，走的是美国常规线路（QNET、ZNET、MCOM 等），回程不经过电信 CN2 优化。延迟方面，电信用户实测三网平均在 170-200ms 之间，联通和移动会稍好一些。适合预算有限、对延迟不敏感的场景，比如跑个轻量服务、做开发测试、学 Linux。

**CN2 GT 线路（DC3）**

CN2 GT 是电信的“中端”优化线路，去程走 CN2，回程仍走普通 163。比纯普通线路好一些，但和 GIA 比有明显差距。目前 DC3 在搬瓦工体系里存在感不强，多数用户会直接跳过它选 GIA-E。

**CN2 GIA-E 线路（DC6 / DC9）**

这是搬瓦工最有代表性的产品线，也是大多数人买搬瓦工的理由。DC6 和 DC9 都在洛杉矶，双程 CN2 GIA，三网回程优化。

- **DC6 CN2 GIA-E**：带宽更大（套餐起步 2.5Gbps，最高 10Gbps），对联通和移动用户更友好，适合长期稳定使用。
- **DC9 CN2 GIA**：路由更纯，电信用户体验和 DC6 接近，移动方向表现也不错。

实际差距比想象中小。如果你不是特别在意某一条线路的细微差异，两个机房随便选都不会踩坑。CN2 GIA-E 套餐还支持免费迁移到日本软银（JPOS_1）、荷兰联通高级线路（EUNL_9）等多个机房，灵活性很高。

**CN2 GIA SLA 线路（DC5）**

这是搬瓦工 2025 年推出的企业级套餐，主打 99.99% SLA 保障——也就是每月宕机时间不超过约 4.32 分钟，超出有赔偿。硬件用 AMD EPYC + NVMe，IO 性能比普通 SSD 套餐强。适合做外贸建站、TikTok 直播这类对稳定性要求高的场景，价格也相应更高。

## 六、几个常见问题

**KVM 套餐能迁移到 CN2 机房吗？**

可以，但迁移到 CN2 机房后，月流量会按 1/3 计算。比如原本 1TB 流量，迁到 CN2 后只剩约 333GB。如果你流量用得多，这个限制要算进去。

**CN2 GIA-E 限量版（$49.99/年那款）现在能买到吗？**

这款是搬瓦工的“传家宝”限量版，长期断货，偶尔补货。补货信息会在搬瓦工的 Telegram 频道（@BandwagonHostNews）和几个中文站的补货通知群推送。能不能抢到看运气，抢不到就买常规 CN2 GIA-E 1GB（$169.99/年），配置更好，价格也只贵一点。

**搬瓦工被封了怎么办？**

搬瓦工提供付费换 IP 服务（部分套餐免费），被封后在 KiwiVM 面板操作即可。SLA 套餐免费换 IP，这也是它比普通 GIA-E 贵的原因之一。

**DC6 和 DC9 选哪个？**

两个都是洛杉矶 CN2 GIA 机房，实际体验差距很小。DC6 带宽更大、对联通移动更友好；DC9 路由更纯、电信体验稳定。随便选一个都不会错，反正 GIA-E 套餐支持免费迁移，用着不满意可以换。
